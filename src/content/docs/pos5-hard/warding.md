## ทำไม vision ตัดสินเกม

ทีมที่เห็นก่อนคือทีมที่เลือกได้ว่าจะสู้หรือหลบ ตัว vision มีสามหน้าที่:

1. **เตือนภัย** รู้ล่วงหน้าเมื่อศัตรูเข้ามา
2. **หาโอกาส** เห็น pickoff หรือ objective ที่ไม่มีคนเฝ้า
3. **ปฏิเสธ vision ของศัตรู** (deny) ทำให้เขาเดินโดยไม่รู้ว่าเรารออยู่

## ชนิดของ ward

| ชนิด | หน้าที่ |
| --- | --- |
| Observer Ward | ให้ vision ในพื้นที่ (มองเห็นแต่ไม่เห็นตัวที่ล่องหน) |
| Sentry Ward | ให้ true sight เห็นตัวล่องหนและ **ทำให้เห็น ward ศัตรูในพื้นที่** เพื่อ deward |

ระยะเวลา ราคา และรายละเอียดเปลี่ยนตาม patch ให้ดู tooltip ในเกม

## หลักการวาง ward

### 1. วางเพื่อ "เตือน" ไม่ใช่เพื่อ "ดู"
ward ที่ดีวางในจุดที่ศัตรูต้องผ่านก่อนมาถึงเรา จึงเห็นเขาก่อนเวลาที่ควรหนี ไม่ใช่วางที่ที่เขาอยู่แล้ว

### 2. ดูว่าเกมอยู่ช่วงไหน
| ช่วง | ควร ward |
| --- | --- |
| เลน | ทางเข้าเลนและป่าที่ศัตรูอาจมา gank |
| ก่อนเก็บ objective | ทางที่ศัตรูจะมาขัด เช่น ก่อนไป Tormentor หรือ Roshan |
| หลังเกมกลาง | จุดที่ศัตรูใช้ฟาร์มหรือเคลื่อนผ่าน |

### 3. อย่าวางที่เดิมทุกเกม
ศัตรูที่เก่งจะรู้ตำแหน่งที่พบบ่อยและ sentry ตรวจได้ เปลี่ยนตำแหน่งบ่อยๆ และใช้พื้นที่ที่ไม่ธรรมดา

### 4. ป้องกัน ward ของตัวเอง
เลือกตำแหน่งที่ศัตรูหาเจอยาก (เช่น หลังต้นไม้หรือมุมที่ต้องเดินอ้อมไปดู) และคอยเช็กว่า ward ยังอยู่ ถ้าโดนลบแสดงว่าศัตรูรู้จุดนั้นแล้ว

## ใน patch 7.41

- แผนที่และภูมิประเทศเปลี่ยน: มีการย้ายจุด Roshan/Tormentor, Lotus Pool, แคมป์ป่าและ tower บางตัว
- แพตช์ 7.41c ทำให้ยูนิตที่บินมองข้ามกำแพงหลุม Roshan ไม่ได้ เห็นภายในหลุมจากข้างนอกไม่ได้และกลับกัน ทำให้การ ward เพื่อดู Roshan ต้องเลือกตำแหน่งที่มองเห็นทางเข้าออก ไม่ใช่มองเข้าไปในหลุมโดยตรง
- แคมป์ป่าที่เปลี่ยนไปทำให้จุด ward เดิมบางจุดอาจไม่เหมาะ ควรทดสอบในเกม

**ข้อควรระวัง:** ตำแหน่ง ward เฉพาะเจาะจงในบทนี้ยังไม่ได้ระบุ เพราะภูมิประเทศเพิ่งเปลี่ยนใน 7.41 ให้ดูแผนที่ในเกมประกอบ

## Deward (ลบ ward ศัตรู)

Deward มีความสำคัญเท่ากับ ward:

1. **ใช้ Sentry ตรวจก่อนเข้า objective** ถ้ามี ward ศัตรูอยู่ ให้ทำลาย
2. **ทำลาย ward ที่ให้ vision บนเส้นทางของทีมเรา**
3. **เลือกจังหวะ** ก่อนทำ objective หรือก่อนไฟต์ ไม่ใช่ระหว่างที่โดนกดดัน
4. **ระวังตัวเอง** เมื่อเข้าไปทำลาย ward เรามักอยู่ในที่เปิดโล่ง

## การจัดการเงินของ Pos 5

| ลำดับ | ซื้ออะไร |
| --- | --- |
| 1 | ward สำหรับทีม |
| 2 | ของฟื้นเลือด/มานาให้ทีม |
| 3 | ของที่ช่วยเราไม่ตายและช่วยทีมสู้ |
| 4 | ของที่ทำให้ทีมเก่งขึ้นเมื่อมีเงินเหลือ |

## ข้อผิดพลาดที่เจอบ่อย

- **วาง ward แล้วลืมเช็กมินิแมพ**
- **ward ทุกเกมที่ตำแหน่งเดิม**
- **ไม่ซื้อ sentry** ทั้งที่ศัตรูใช้ ward เยอะ
- **เดินไป ward คนเดียวลึกเกินไป** แล้วโดนจับตายและเสีย vision

## TL;DR

- ward เพื่อเตือน ไม่ใช่เพื่อดู
- ตำแหน่งต้องเปลี่ยนไม่ซ้ำ และต้องปกป้อง
- ใช้ sentry เพื่อ deward ก่อนทำ objective
- 7.41 เปลี่ยนภูมิประเทศ ให้ทดสอบจุด ward ในเกมก่อนใช้

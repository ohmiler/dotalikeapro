## Pos 3 ในเกมกลาง

พ้นช่วงเลน Pos 3 มีหน้าที่หลักสองอย่างที่ทีมต้องการที่สุด:

1. **เปิดไฟต์ (initiate)** ให้ทีมเข้าสู้ในจังหวะที่เราเลือก
2. **สร้างพื้นที่ (space creation)** ให้แครี่และมิดฟาร์มได้ ด้วยการกดดันศัตรูและดึงความสนใจ

Pos 3 ไม่ใช่ตำแหน่งที่ต้องได้ kill มากที่สุด แต่เป็นตำแหน่งที่ **เปิดโอกาสให้คนอื่นได้ kill**

## หลักการเปิดไฟต์

### 1. เปิดเมื่อสกิลพร้อม ทีมพร้อม และศัตรูไม่พร้อม
ก่อนเปิดตรวจสามข้อ:
- สกิลเปิดของเราพร้อมหรือยัง
- ทีมอยู่ในระยะที่ตามมาสู้ได้หรือไม่ (ไม่ใช่กระจายอยู่ไกล)
- ศัตรูใช้สกิลสำคัญไปแล้วหรือกำลังคูลดาวน์

### 2. เปิดให้ถูกเป้า
เปิดด้วยการจับตัวที่ทีมต้องการที่สุด เช่น ตัวที่สร้างความเสียหายสูงหรือตัวที่ป้องกันทีมศัตรู ไม่ใช่ตัวที่ใกล้ที่สุด

### 3. เปิดด้วยจำนวนที่ได้เปรียบ
ถ้าจับตัวเดียวได้และศัตรูที่เหลือมาช่วยไม่ทัน นั่นคือ pickoff ที่ดีที่สุด

## สิ่งที่ผู้เล่นระดับสูงดูก่อนเปิด

| ตรวจสอบ | ทำไม |
| --- | --- |
| Blink หรือสกิลเปิดของศัตรู | ถ้าศัตรูพร้อมสวน เราอาจถูกจับก่อน |
| ตำแหน่งของ TP/ป้องกัน | ถ้าศัตรู TP มาช่วยได้ เราต้องเปิดเร็ว |
| ตำแหน่งของทีมเรา | ถ้าไกลเกินไป ให้รอ |
| จำนวน tower/ป่าใกล้ที่เป็นพื้นที่ล่าถอย | ถ้าไฟต์ไม่ดี เราต้องมีที่ถอย |

## สร้างพื้นที่ (space creation)

การสร้างพื้นที่คือการทำให้แครี่ฟาร์มได้ปลอดภัย โดยการ:

- **กดดัน tower ศัตรู** ด้วยตัวเราเอง เพื่อบังคับให้ศัตรูส่งคนมาป้องกัน
- **ยืนหน้า** ทำให้ศัตรูเจอเราก่อนแครี่
- **ฟาร์มพื้นที่ที่ศัตรูต้องการ** เช่น ป่าหรือเลนของเขา

ผลคือศัตรูต้องเลือกระหว่างไล่ตามเราหรือปล่อยให้เราผลักต่อ ทั้งสองทางเป็นผลดีของทีม

## Tormentor และ objective

Tormentor เป็นเป้าหมายที่ทีมต้องช่วยกัน และ Pos 3 มักเป็นคนเริ่มเมื่อมีช่วงเวลาปลอดภัย (ดูบท [Timings](/fundamentals/timings/) ว่าเกิดครั้งแรก 20:00 และให้ Aghanim's Shard) การกด Tormentor เปิดให้แลกกับการสู้ โดยเราต้องเตรียมใจว่าศัตรูอาจมาขัด

## ข้อผิดพลาดที่เจอบ่อย

- **เปิดไฟต์คนเดียว** ทั้งที่ทีมยังไม่ตามมา
- **เปิดในจังหวะที่ศัตรูพร้อมมากกว่า** แล้วโดนตายก่อนทีมเข้ามา
- **ไม่ตัดสินใจ** ทำให้ทีมชะงักในจังหวะที่ควรเข้า
- **เก็บของป้องกันช้า** ทั้งที่ต้องอยู่หน้าไฟต์

## TL;DR

- Pos 3 เปิดไฟต์และสร้างพื้นที่ให้ทีม
- เปิดเมื่อสกิลพร้อม ทีมพร้อม และศัตรูไม่พร้อม
- เลือกเป้าที่ทีมต้องการ ไม่ใช่ตัวที่ใกล้ที่สุด
- กดดันเพื่อบังคับให้ศัตรูส่งคนมา

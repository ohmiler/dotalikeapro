## เป้าหมายของ Pos 3

เลนของ Pos 3 (ออฟเลน) มักถูกมองว่าเป็นเลนที่ยากที่สุด (ความเห็นทั่วไปของผู้เล่น ไม่ใช่สถิติ) เพราะอยู่ตรงข้ามกับเซฟเลนของศัตรู ซึ่งมักมีตัวแครี่และซัพพอร์ตอยู่ด้วยกัน เป้าหมายจึงไม่ใช่ชนะเลน แต่คือ:

1. **ไม่แพ้เลนจนเสียเปรียบเกินไป**
2. **ได้ XP และทรัพยากรพอสมควร**
3. **รบกวนแครี่ศัตรูให้ฟาร์มไม่สะดวก**
4. **เตรียมพร้อมเป็นตัวเปิดไฟต์ของทีม**

## ใน patch 7.41

ตามแพตช์โน้ตทางการ:

- จุดที่ครีปเจอกันขยับเข้ามาทางเลนออฟเลน ครีปฝั่งออฟเลนออกจากฐานช้าลงเล็กน้อยเป็นเวลาสั้นๆ ส่วนครีปเซฟเลนเร็วขึ้นเล็กน้อย (มีผลถึง 7:30)
- Lotus Pool ถูกย้ายเข้าใกล้ tower ออฟเลนของแต่ละฝั่ง และจุดเกิด Tormentor ถูกย้ายเข้าใกล้ Lotus Pool

**ข้อสรุปของเว็บนี้ (ไม่ใช่ข้อความทางการ):** ข้อแรกน่าจะทำให้ออฟเลนมีพื้นที่น้อยลงในช่วงต้นเกม จึงควรเล่นรอบคอบกว่าเดิม ส่วนข้อสอง หมายถึง objective เหล่านี้อยู่ใกล้ฝั่งออฟเลนมากขึ้น ซึ่งอาจเปิดโอกาสให้ Pos 3 เข้าถึงได้เร็วกว่า

## วางแผนก่อนเริ่มเลน

| คำถาม | ผลต่อการเล่น |
| --- | --- |
| ฮีโร่ของเราเก่งเลนหรือไม่? | ถ้าไม่ ให้ยืนนอกระยะและรับ XP ห่างๆ |
| ศัตรูมีตัวที่ harass แรงหรือไม่? | ถ้ามี ให้ใช้ป่าหรือแคมป์ข้างเคียงเป็นทางเลือก |
| ซัพพอร์ตของเราเป็นแบบใด? | ประสานให้ซัพพอร์ตช่วย pull หรือ harass |
| Neutral item Tier 1 ที่มีตั้งแต่ 0:00 ช่วยเราได้ไหม? | เลือกของที่ช่วยให้อยู่เลนได้นานขึ้น |

## หลักการยืนเลน

1. **อยู่ในระยะที่ได้ XP แต่ไม่ถูก harass** ยืนห่างจากศัตรูให้พ้นระยะโจมตีแต่ใกล้พอที่จะรับ XP จากครีปที่ตาย
2. **ใช้ต้นไม้และพุ่มไม้บังสายตา** ทำให้ศัตรูไม่แน่ใจว่าเราจะทำอะไร
3. **อย่าฟาร์มทุกตัว** ยอมเสียครีปบางตัวเพื่อไม่ให้โดน harass หนัก
4. **ใช้ครีปเป็นโล่** ยืนหลังครีปตัวเอง และเลี่ยงเข้าใกล้ศัตรูโดยไม่มีครีปคุ้ม
5. **ใช้แคมป์ป่าถ้าเลนแย่มาก** แคมป์เล็กใกล้เลนช่วยฟื้นฟูฟาร์มได้

## เมื่อไรควรสู้

| สถานการณ์ | ควรทำ |
| --- | --- |
| ศัตรูใช้สกิลไปแล้ว | เข้า harass หรือบังคับเป็นการแลกหมัดที่เราได้เปรียบ |
| ครีปเรามากกว่าครีปศัตรู | ผลักเลนไปหา tower ศัตรู |
| ซัพพอร์ตศัตรูออกไป pull หรือ rotate | กดดันแครี่ที่อยู่ตัวเดียว |
| เราเลเวลสูงกว่า | ใช้สกิลกดดัน และแลกหมัดได้ |

## ทางเลือกเมื่อแพ้เลนแล้ว

- **ยกเลิกเลน** ไปฟาร์มป่าและกลับมาเมื่อเข้าที่
- **สลับกับเลนอื่นถ้าทีมช่วย**
- **ยอมเสียบาง tower** ถ้าเป็นการแลกกับ objective อื่น

การยอมรับว่าแพ้เลนเร็ว ดีกว่าดันทุรังจนเสียทรัพยากรมาก

## ข้อผิดพลาดที่เจอบ่อย

- **เข้าไปฟาร์มใกล้ศัตรูเกินไป** จนโดน harass และหมดเลือด
- **ไม่ถอยเมื่อเลือดต่ำ** ทั้งที่ยอมกลับบ้านคุ้มกว่าตาย
- **ไม่ประสานกับซัพพอร์ต** เลนเลยไม่มีความร่วมมือ
- **ลืมดูมินิแมพ** ทั้งที่เลนนี้มีความเสี่ยงโดน gank สูง

## TL;DR

- เป้าหมายคือไม่แพ้เลน ไม่ใช่ชนะเลน
- 7.41 ทำให้ศัตรูได้เปรียบเรื่องจุดปะทะจนถึง 7:30
- ยืนห่างแต่รับ XP ใช้ต้นไม้บังตา
- แพ้แล้วยกเลิกเลนเร็วดีกว่าดันทุรัง

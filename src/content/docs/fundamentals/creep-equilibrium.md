## Creep equilibrium คืออะไร

ครีปสองฝั่งเดินมาชนกันที่จุดหนึ่งบนเลน เรียกว่าจุดสมดุล (equilibrium) จุดนี้ไม่ได้คงที่ มันขยับตามว่าใครฆ่าครีปได้มากกว่า:

- **จุดปะทะใกล้ tower ศัตรู** → เรามีพื้นที่ ฟาร์มปลอดภัย ศัตรูต้องเข้ามาหาเรา
- **จุดปะทะใกล้ tower เรา** → เราโดนกด ต้องยืนใต้ tower ศัตรูยิงเราแลกกับ last hit ได้ยาก

เป้าหมายของช่วงเลนคือ **ทำให้จุดปะทะอยู่ในตำแหน่งที่เราได้เปรียบ** ไม่ใช่แค่ last hit ให้มากที่สุด

## อัปเดตใน patch 7.41

ข้อมูลนี้ยืนยันจากแพตช์โน้ตทางการของ 7.41:

- **จุดที่ครีปเจอกันขยับไปทางเลนออฟเลน** — ครีปฝั่งออฟเลนถูกทำให้ช้าลงเล็กน้อยเป็นเวลาสั้นๆ หลังออกจากฐาน ส่วนครีปฝั่งเซฟเลนถูกทำให้เร็วขึ้นเล็กน้อย
- **มีผลถึงนาที 7:30 เท่านั้น** หลังจากนั้นกลับเป็นปกติ
- ผลคือเซฟเลนได้เปรียบเรื่องพื้นที่ในช่วงต้นเกมมากขึ้น และออฟเลนต้องคิดเรื่องการยืนเลนหนักกว่าเดิม (ดูบท [ยืนเลนยาก](/pos3-offlane/laning/))

## วิธีคุมจุดปะทะ

### 1. ทำให้ครีปของเราชนะการปะทะ
ครีปที่เหลือเยอะกว่าจะดันจุดปะทะไปหาศัตรู วิธีคือ **deny ครีปตัวเอง** ตอนเลือดต่ำกว่า 50% เพื่อตัดจำนวนครีปฝั่งเราที่ตายเอง และ last hit ครีปศัตรูตัวที่ใกล้ตาย

### 2. เรียก aggro
เมื่อฮีโร่ตีฮีโร่ฝั่งตรงข้ามขณะอยู่ในระยะของครีปฝั่งนั้น ครีปกลุ่มนั้นจะหันมาตีฮีโร่ที่โจมตี (creep aggro) นำมาใช้ได้แบบนี้:

- ตีฮีโร่ศัตรูหนึ่งทีตอนครีปเขาอยู่ใกล้ แล้วถอย ครีปศัตรูจะวิ่งตามเรา ทำให้ครีปเราฟาดครีปศัตรูได้ฟรี
- ใช้เพื่อ **ดึงครีปเข้าหา tower** ก่อนที่ครีปสองฝั่งจะชนกัน
- ระวัง: ถ้าทำผิดที่ ครีปศัตรูทั้งกลุ่มจะตีเรา

### 3. ใช้ block ครีปตัวเอง
ยืนขวางทางครีปของเราไม่ให้เดินต่อ ทำให้ครีปศัตรูมาเจอครีปเราช้าลง จุดปะทะจึงอยู่ใกล้ tower เรามากขึ้นตามที่ตั้งใจ เหมาะเมื่อเราอยากให้ครีปไปชนตรง tower ตัวเอง

### 4. Pull ครีปป่า
ดึงครีปป่ามาสู้กับครีปเลนเพื่อเปลี่ยนจุดสมดุล (ดูบท [Pull และ stack](/pos4-soft/pull-and-stack/))

## อ่านสถานการณ์เลน

| เห็นอะไร | หมายความว่า | ควรทำ |
| --- | --- | --- |
| ครีปเราน้อยกว่า | จุดปะทะกำลังหนีไปทาง tower เรา | ห้ามกดครีปเพิ่ม ใช้ aggro เรียกครีปศัตรูมา |
| ศัตรูชอบยืนหลังครีป | เขากำลังกลัวโดน harass | กด harass ต่อเพื่อดัน mana/เลือดเขา |
| ศัตรูไม่มาที่เลน | อาจไป rotate หรือรอ gank | ระวังมินิแมพ ถอยห่างจากพุ่มไม้ |

## TL;DR

- ตำแหน่งที่ครีปปะทะสำคัญกว่าจำนวน last hit ในช่วงเลน
- ใน 7.41 เซฟเลนได้เปรียบเรื่องจุดปะทะจนถึงนาที 7:30
- ใช้ deny + aggro + block เพื่อดันจุดปะทะไปหาศัตรู
- เห็นครีปเราน้อยกว่า ต้องหยุดฟาร์มตามปกติและแก้ตำแหน่งก่อน

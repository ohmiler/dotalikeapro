> **ระดับความมั่นใจของบทนี้** ส่วน "ใน patch 7.41 มีอะไรเปลี่ยน" ตรวจกับแพตช์โน้ตทางการแล้ว ส่วนวิธี pull และ stack เป็นความรู้ทั่วไปของเกม ผมไม่พบตัวเลขในแพตช์โน้ตที่ยืนยันได้ (เช่น วินาทีที่ควรดึง) ให้ทดสอบใน Demo Hero ก่อนใช้ในเกมจริง

## Pull คืออะไร

Pull คือการเรียกครีปป่า (aggro) แล้วพาไปให้ชนกับครีปเลนฝั่งเรา ครีปเลนของเราจึงต้องเสียเวลาสู้กับครีปป่าก่อนไปเจอครีปศัตรู แพตช์โน้ต 7.37 มีข้อความที่ยืนยันว่ากรณีนี้เกิดขึ้นจริง (ครีปป่าที่ถูก pull จะถูกครีปเลนโจมตี)

**ผลที่ผู้เล่นมักตั้งใจ** คือเลื่อนจุดสมดุลของครีป (ดูบท [คุมเลน](/fundamentals/creep-equilibrium/)) เข้าใกล้ tower ของฝั่งเรา เช่น เพื่อให้ตัวที่ฟาร์มเลนได้ฟาร์มใกล้ tower ปลอดภัยขึ้น ผลจริงขึ้นกับจังหวะและว่าครีปเลนอยู่ตรงไหน จึงต้องทดสอบเอง

Pull ใช้ได้กับ Pos 4/5 ที่ไปช่วยเลน

## Stack คืออะไร

Stack คือการดึงครีปป่าออกจากแคมป์ก่อนที่แคมป์ใหม่จะเกิด เพื่อให้มีครีปในแคมป์เพิ่ม ผลคือครีปที่ฟาร์มได้ต่อครั้งมากขึ้น เป็นวิธีเพิ่มฟาร์มให้ Pos 1–3 โดยไม่ต้องใช้เวลาของตัวเอง

**หลักการสั้นๆ (ความรู้ทั่วไป):**
1. แคมป์เกิดใหม่ทุกต้นนาทีเมื่อไม่มียูนิตค้างอยู่ในแคมป์
2. เราต้องดึงครีปออกจากพื้นที่แคมป์ก่อนต้นนาทีถึง
3. ครีปใหม่เกิดซ้อนกับครีปเดิมที่เราดึงไป
4. ทำซ้ำเพื่อ stack ได้หลายชั้น

ช่วงเวลาที่ต้องดึงโดยประมาณคือวินาทีที่ 53 ถึง 55 ของแต่ละนาที แต่ต่างกันตามแคมป์ (ค่าประมาณ ไม่ได้มาจากแพตช์โน้ต)

**ข้อจำกัดที่ยืนยันจากแพตช์โน้ต 7.38:** ถ้าแคมป์ถูกบล็อก ยูนิตจะไม่ถูกอัปเกรด และจำนวนยูนิตที่ถูกอัปเกรดไม่เพิ่มตามการ stack (เช่น แคมป์ที่มี ancient ตัวเดียว stack แล้วก็ไม่ได้ ancient เพิ่ม)

## ใน patch 7.41 มีอะไรเปลี่ยนที่กระทบ

จากแพตช์โน้ตทางการ 7.41:

- แคมป์ ancient ใกล้ปลายลำธารถูกลดเป็นแคมป์กลางและย้ายเข้าใกล้ฐาน
- แคมป์กลางใกล้ประตูป้องกันเลนออฟเลนถูกลดเป็นแคมป์เล็ก
- tower tier 1 ของเซฟเลนถูกย้ายห่างจากแคมป์ pull และจุดที่ครีปเจอกัน
- ต้นไม้บางส่วนของแคมป์ pull ถูกเอาออก
- แคมป์ที่ท่วมน้ำ (flooded) ใกล้ tower เซฟเลน tier 2 พัฒนาเป็นแคมป์ใหญ่ได้ครั้งเดียว ส่วนแคมป์ใกล้ bounty rune พัฒนาเป็น ancient ได้สองครั้ง

ผลรวมคือ **ตำแหน่ง pull และ stack ที่เคยใช้อาจไม่ตรงอีกต่อไป** ให้ตรวจแผนที่ใหม่

## ก่อนตัดสินใจ pull

ผมไม่ได้เขียนตารางว่า "ควร/ไม่ควร pull เมื่อไร" เพราะไม่มีข้อมูลทางการรองรับ และคำตอบขึ้นกับตำแหน่งครีปในเลนตอนนั้น ให้ถามตัวเองสามข้อ:

- ตอนนี้จุดสมดุลอยู่ตรงไหน และเราอยากให้มันอยู่ตรงไหน
- เรามีเวลาพอไหม โดยไม่ทิ้งเลนหรือโดน gank
- เรามี vision พอจะรู้ว่ามีใครมาไหม

## Stack ที่ดีต้องไม่เสียหาย

- ก่อน stack **เช็กว่าแคมป์ปลอดภัย** ไม่มีศัตรูซ่อนอยู่
- อย่าทิ้งเลนตอนที่เพื่อนต้องการความช่วยเหลือ
- ให้บอกผู้ฟาร์มว่า **stack พร้อมแล้ว** ไม่งั้นเสียเปล่า

## ประสานกับ Pos 1–3

การ stack ไม่มีประโยชน์ถ้าไม่มีใครมาเก็บ พูดคุยล่วงหน้าเรื่อง:

- แคมป์ไหน stack ให้ใคร
- Pos 1/2 ไปเก็บตอนไหน
- ถ้าศัตรูมาขัด ทำอย่างไร

## TL;DR

- Pull ใช้คุมจุดปะทะ Stack ใช้เพิ่มฟาร์ม
- ดึงก่อนต้นนาทีราววินาทีที่ 53–55 (ค่าประมาณ ต้องทดสอบเอง)
- 7.41 เปลี่ยนแคมป์และตำแหน่ง pull ต้องตรวจแผนที่ใหม่
- บอกผู้ฟาร์มเสมอเมื่อ stack พร้อม
